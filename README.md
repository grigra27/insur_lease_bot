## Историческая функциональность

Бот помогал найти информацию о страховании предметов лизинга в локальной CSV-базе `tariffs_online.csv`. Пользователь отправлял название имущества, марку или модель обычным текстом. Поиск учитывал нормализацию текста и пробовал близкие варианты, если прямых совпадений не было.

По найденным записям бот показывал:

- количество совпадений;
- минимальную, медианную и максимальную стоимость имущества в миллионах рублей;
- минимальный, медианный и максимальный страховой тариф в процентах;
- наиболее частый тип страхования;
- наиболее частую страховую компанию.

Это была статистика по загруженной базе. Бот не запрашивал текущие предложения страховых компаний.

## Команды и административные функции

- `/start` — приветствие, количество записей в базе и краткая инструкция;
- `/help` — справка;
- `/digest` — отправка дайджеста запросов администратору, доступная только администратору.

Запросы пользователей записывались в `user_queries.log`. Встроенный ежедневный планировщик отправлял администратору дайджест за последние 24 часа. Обработчик ошибок уведомлял администратора о проблемах при выполнении поиска.

Скрипт `send_digest_once.py` был дополнительным одноразовым отправителем того же дайджеста для возможного внешнего запуска. В обследованном развёртывании внешних cron-задач или systemd hooks проекта не обнаружено. Дайджест обслуживал внутренний планировщик бота.

## Сохранённая структура

- `bot.py` — поиск, обработчики Telegram, журналирование и внутренний планировщик дайджестов;
- `send_digest_once.py` — исторический одноразовый отправитель дайджеста;
- `requirements.txt` — зависимости Python;
- `Dockerfile` и `docker-compose.yml` — историческая конфигурация контейнера;
- [docs/archive/deploy.yml.disabled](docs/archive/deploy.yml.disabled) — бывший workflow автоматического развёртывания.

CSV-база, `.env` и журнал запросов не входят в Git-репозиторий. Они сохраняются только в частной резервной копии вместе с другими серверными данными; её содержимое не публикуется.

В последнем развёртывании использовались один контейнер, загрузка CSV в память при запуске, Docker healthcheck и ротация контейнерных журналов. Основными зависимостями были `python-telegram-bot`, `pandas`, `python-dotenv` и `APScheduler`.
